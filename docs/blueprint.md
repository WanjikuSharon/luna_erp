# **App Name**: Luna Industries ERP

## Core Features:

- Raw Material Request: Operation managers can request the delivery of raw materials needed for production.
- Delivery Verification: Operation managers can check if the delivered raw materials match the request and upload the delivery note.
- Stock Update: Operation managers can add the verified raw materials to the existing stock, updating the inventory.
- Production Input: Production personnel can specify the raw materials used for manufacturing.
- Production Output: Production personnel can indicate the quantity of product produced, updating Luna's inventory automatically.
- Inventory Update AI Tool: A generative AI powered tool that can update Luna's inventory in case the update has an discrepancy between the input vs output reported quantities and providing a best-effort reason for such discrepancy, after checking through previous inventory information
- Admin Dashboard: Admin users have read-only access to all ERP data and can monitor all actions performed by other users.

## Style Guidelines:

- Primary color: Golden yellow (#FFD700) to evoke the warmth and richness of the Kenyan landscape.
- Background color: Light sky blue (#E1F5FE), a desaturated version of the primary color that still carries the sky blue vibe.
- Accent color: Light Orange (#FFB347), an analogous hue to gold. to represent energy and vibrancy.
- Font pairing: 'Playfair' (serif) for headlines, providing a high-end feel, paired with 'PT Sans' (sans-serif) for body text.
- Use icons representing local Kenyan culture, industries and landscapes.
- Responsive layout optimized for various screen sizes, ensuring accessibility on all devices.
- Subtle transitions and animations to enhance user experience and provide feedback on interactions.
