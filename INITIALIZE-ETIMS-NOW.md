# 🚀 Quick: Initialize Your eTIMS Device

## Run This Command Now:

```bash
npx ts-node scripts/init-etims.ts
```

## What You'll Get:

```
✅ SUCCESS! Device initialized successfully!

ETIMS_API_KEY=LUNA_19_2025
ETIMS_API_SECRET=ABC123XYZ789...  ← Copy this!
ETIMS_DEVICE_SERIAL=LUNA_19_2025
ETIMS_COMPANY_PIN=P052454082G
ETIMS_BRANCH_ID=00
```

## Then:

1. **Copy** those credentials
2. **Paste** them into `.env.local` (replace the placeholder values)
3. **Restart** your dev server: `npm run dev`
4. **Done!** The 500 error on KRA portal should be gone
